# HITO-007 — Catálogos agrícolas y del módulo de requerimientos

## Estado

**CERRADO** — 2026-08-24. Se pueblan los catálogos que consumen las pantallas de requerimientos y
programación. Incluye las migraciones V6-V9, el paquete backend `catalogos` y la alineación del
contrato mobile. El bloque abarca lo planificado como HITO-006 (fundos/variedades/lotes) y
HITO-007 (etapas fenológicas/plagas/nematodos/patrones), entregado en un único commit coherente.
