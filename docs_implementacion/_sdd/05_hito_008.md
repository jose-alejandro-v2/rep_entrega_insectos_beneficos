# HITO-008 — Backend del Módulo de Requerimientos

## Estado

**IMPLEMENTADO — pendiente de commit y push** — 2026-08-25. Se implementa el backend del módulo de Requerimientos: migración V10,
paquete `requerimientos` (entidad, repositorio, DTOs, mapper, service, resources) y endpoint de
stock. Con esto queda completo el flujo de requerimientos (mobile del HITO-005 + backend), usando
los catálogos poblados del HITO-007.

**Decisión del usuario:** **sin bump de versión** (se mantiene **1.4.0**) — este hito no modifica el
artefacto mobile (solo backend); el bump se evaluará al validar el flujo completo en el celular y
generar el APK release.

## Alcance implementado

### Migración
- **V10** `create requerimientos`: tabla `requerimientos` con FKs a `fundos`, `lotes`, `especies`,
  `etapas_fenologicas`, `plagas`, `usuarios` (creado_por); `estado` CHECK del ciclo
  REGISTRADO→PENDIENTE→APROBADO→ENTREGADO→RECIBIDO→LIBERADO; stock_disponible; fecha/hora
  liberación; observaciones; papel_con_postura; sobre_con_cascarilla; timestamps; 4 índices.

### Backend (`pe.sistema.insectosbeneficos.requerimientos`)
- `Requerimiento` (JPA, patrón `programacion`), `RequerimientoRepository` (filtros + suma por especie),
  DTOs (`RequerimientoDto` shape exacto del contrato mobile, `CrearRequerimientoRequest`,
  `ActualizarRequerimientoRequest`, `StockDto`), `RequerimientoMapper`, `RequerimientoService`
  (listar/obtener/crear/actualizar + stock disponible), `RequerimientoResource`, `StockResource`.

### Endpoints (RBAC `Super Admin`/`Admin`/`Usuario`)
- `GET /api/v1/requerimientos?fechaDesde&fechaHasta&estado&creadoPor`
- `GET /api/v1/requerimientos/{id}`
- `POST /api/v1/requerimientos` → 201
- `PUT /api/v1/requerimientos/{id}`
- `GET /api/v1/programaciones/{especieId}/stock` → `{ stock }`

### Reglas de negocio
- Ciclo de estados solo hacia adelante; LIBERADO es terminal.
- ENTREGADO exige papel+sobre con suma == cantidad (RF-165).
- Crear valida catálogos (404) y cantidad > 0 / ≤ stock (400).
- Stock disponible = programación más reciente de la especie − Σ requerimientos (mín 0).
